**Q. Raffinose is used as a marker for what?** 
?
**Ans:** **Extracellular fluid (ECF) volume.**
**Why?**  
Raffinose distributes mainly in the **extracellular compartment** and does not readily enter cells, so it can be used to estimate **ECF volume**.
**Remember:**
- **Raffinose → ECF volume**
- **Inulin → GFR**
- **D₂O (deuterium oxide) → Total body water (TBW)**
